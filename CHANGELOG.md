Significant changes only (CLAUDE.md rule 5): one line per change, 1–2
sentences — essence and intent, not content.

- 2026-08-16: Spec (narrative + formal + error JSON Schema) — the closed error vocabulary now carries the `payment_failed` 402 the pay path has emitted since the PSP-failure fix, so a schema-validating client stops rejecting a legitimate response; the row states what a bare "402" hides, that this third 402 is not a gate and deliberately carries no `WWW-Authenticate`, and that its `hint` separates a definitive decline from an unknown outcome. The two pages that promised a challenge header on "each 402" are corrected to say "each of the two gates". Intent: a vocabulary published as closed and stable must actually contain what the wire sends. (K-665)
- 2026-08-16: Spec (narrative + formal) — the three per-response version headers the reference has always emitted (`Kiosk-Server-Version`, `Kiosk-API-Version`, `Kiosk-Min-Client`) are now specified: REQUIRED to emit on every mount-path response, OPTIONAL to consume, with the server stamp marked opaque and the client floor marked advisory, and both pages say plainly that these are not the "three version lines" of the versioning section. Intent: the reference's own conformance harness asserted a contract no normative document stated, so a porter working from the spec alone failed it. (K-676)
- 2026-08-13: Operator onboarding — Step 3 teaches the one line that ships (`mount Kiosk::Server::Engine => Kiosk.configuration.mount_path`) instead of a fifteen-line hand-written route table, and states what that line actually draws: the wire, the proof-of-possession auth plane, JWKS, KYC attestation, the whole account-binding ceremony, and the root-served discovery documents including `/auth.md` — the last three of which the hand-written list silently omitted, so an operator copying it published an `/auth.md` link its own discovery document made but the app never answered, and offered no way to bind an assistant to an existing account. Hand-drawing survives as a labelled escape hatch, framed the way kiosk-server's README frames it. Intent: the page's most-copied step must install the whole surface, not the part someone once transcribed. (K-505)
- 2026-08-12: Descriptor house style — the guide now presents descriptors as what they are in the shipped reference: the `Kiosk::Query`/`Kiosk::Action` controller macros, with the worked hotel-search example rewritten from a registration block to a controller and `output_schema` promoted from "planned" to a required field of the house style (it is served in the catalog wherever declared; the formal descriptor schema's own declaration of the field is noted as still to follow).
